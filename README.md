# 🇯🇵 KanaSensei

KanaSensei is a simple web app for practicing the Japanese **Katakana** alphabet.

It is designed to work on any modern web browser and can be installed on an iPhone using **GitHub Pages** and **"Add to Home Screen"**.

## Features

* 🎴 Random Katakana practice
* 👆 Tap anywhere to reveal the rōmaji
* 🔀 No repeated characters until all Katakana have been shown
* 📖 View the complete Katakana alphabet
* 📱 Works great on iPhone and desktop browsers
* 🌐 Hosted with GitHub Pages

## How to Use

1. Open the app.
2. A random Katakana character is displayed.
3. Tap anywhere on the screen to reveal its rōmaji.
4. Tap **"Next Kana"** to continue.
5. Use **"Show all Kana"** to view the complete Katakana chart.
